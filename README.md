# antrel-os

Личная система на базе Fedora Workstation. В репозитории лежит всё, чтобы получить ту же систему с нуля:
установщик (`setup.sh`), списки программ и настройки. Агент держит репозиторий в актуальном состоянии:
поменяли настройку — она попадает сюда.

Прошлая версия на NixOS сохранена под тегом `nixos-archive`.

## Состав

| Слой | Что |
|---|---|
| Основа | Fedora Workstation 45; GNOME остаётся запасным рабочим столом |
| Загрузка | GRUB Fedora, пункт Windows в меню |
| Видео | NVIDIA из RPM Fusion (`akmod-nvidia`, открытые модули ядра), VA-API |
| Звук | PipeWire |
| Отзывчивость | `scx_bpfland` через `scx_loader`, повышенный вес CPU пользовательской сессии |
| Рабочий стол | Hyprland (uwsm) + рабочий стол [43PR](https://github.com/43PR/dotfiles): панель, меню и окно настроек на Quickshell, лаунчер rofi, 27 тем и цвета от обоев |
| Шрифты | JetBrains Mono, Iosevka и Symbols Nerd Fonts, Inter; субпиксельное сглаживание, хинтинг, stem darkening |
| Программы | Firefox, kitty + zsh + Starship, Thunar, Vesktop (Discord), Happ (VPN), omp |

## Как устроен репозиторий

```
setup.sh                  установщик: из чистой Fedora Workstation делает antrel-os; можно запускать повторно
packages/dnf.txt          программы из репозиториев Fedora, RPM Fusion и COPR
packages/copr.txt         подключаемые COPR-репозитории (и какие пакеты из них можно брать)
packages/flatpak.txt      программы с Flathub
system/                   системные файлы: копируются в / как есть (system/etc/... → /etc/...)
home/                     настройки пользователя: лежат здесь, в ~ на них ссылки (рабочий стол 43PR — тоже здесь)
links.txt                 какие пути из home/ связаны ссылками с ~
43pr-upstream.txt         с какой версии 43PR взят рабочий стол; наши правки помечены комментарием «antrel-os»
track.sh                  взять новую настройку под git: ./track.sh ~/.config/что-то
AGENTS.md                 контекст для агента: решения, правила, чек-лист первой загрузки
docs/design/              визуальные референсы
```

Настройки из `home/` подключены ссылками: `~/.config/hypr` — это `~/antrel-os/home/.config/hypr`. Любое
изменение (руками, агентом или в окне настроек 43PR, Super+I) сразу видно в git, остаётся сделать коммит.
Тема и обои тоже здесь: `home/.local/state/43pr` и `home/Pictures/Wallpapers` (видеообои в git не попадают).

## Установка с нуля

### 1. Подготовка в Windows

- Свободные ~40 ГБ сразу после `C:` («Управление дисками» → правой кнопкой по `C:` → «Сжать том»).
  Если там уже есть раздел (например, `nixos` из прошлой попытки): правой кнопкой по нему → «Удалить том».
  Раздел без буквы на 40 ГБ; `C:`, «Восстановление» и EFI не трогать.
- Гибернация и быстрый запуск выключены: в терминале администратора `powercfg /h off`.
- Скачать **Fedora Workstation 45** (Live ISO, x86_64) с [fedoraproject.org/workstation](https://fedoraproject.org/workstation/download)
  и записать на флешку через Rufus (режим **DD**, если спросит) или Fedora Media Writer («Выбрать .iso файл»).
- Интернет по кабелю.

### 2. Живая система с флешки

При включении открыть меню загрузки (на Huananzhi обычно F11) и выбрать «UEFI: <флешка>». Загрузится Fedora
с флешки, ничего не устанавливая. Проверить: оба монитора показывают картинку, есть интернет.

### 3. Установка Fedora

«Установить на жёсткий диск» (Install Fedora). В установщике:

1. Язык и раскладка.
2. **Способ установки: «Использовать свободное место» (Use free space)**. Не «Использовать весь диск»: он
   стирает Windows. Если установщик предлагает удалить или сжать какие-то разделы — ничего не удалять.
3. Шифрование диска — не включать.
4. Пользователь: имя `antrel`, пароль; галочка администратора включена.
5. Проверить итог: изменения только в свободном месте → «Установить». Перезагрузиться, вынуть флешку.

### 4. Одна команда

Войти в GNOME, открыть терминал (Win → «Терминал») и выполнить:

```sh
curl -fsSL https://raw.githubusercontent.com/AntrelL/antrel-os/main/setup.sh | sudo bash
```

Скрипт (сообщения на английском) скачает репозиторий в `~/antrel-os`, покажет план и спросит `yes`. Дальше
сам: зеркала, обновление системы, репозитории, программы, драйвер NVIDIA, системные файлы, ссылки на
настройки, omp. Ошибка в одной части не останавливает остальные: в конце будет список того, что не получилось
(«Finished with errors»), — тогда запустить `sudo ~/antrel-os/setup.sh` ещё раз, сделанное пропускается.
Займёт от 20 минут до часа (скачивание, сборка драйвера).

### 5. Первый вход

1. `sudo reboot`.
2. На экране входа: выбрать пользователя → шестерёнка внизу справа → **«Hyprland (uwsm-managed)»** → пароль.
   Экран входа запомнит выбор; GNOME остаётся в том же меню как запасной вариант.
3. **VPN:** Super+D → `Happ` → добавить подписку (ссылка из Happ на Windows; в репозитории её нет) → подключиться.
4. **GitHub:** в терминале (Super+T) `gh auth login`.
5. **Агент:** при включённом VPN `cd ~/antrel-os && omp`, первая просьба: «пройди чек-лист после первой загрузки».

## Ежедневная работа

```sh
sudo dnf upgrade                 # обновить систему
sudo ~/antrel-os/setup.sh        # применить изменения из packages/ и system/ (повторный запуск безопасен);
                                 # то же самое — кнопка UPDATE DESKTOP в Super+I → Updates
~/antrel-os/track.sh ~/.config/X # взять под git настройки новой программы
```

После обновления ядра драйвер NVIDIA пересобирается сам; перезагружаться стоит через пару минут после
окончания `dnf upgrade`.

Если Hyprland не запускается: на экране входа выбрать GNOME, починить, вернуться. Если не загружается вся
система: в меню GRUB выбрать предыдущее ядро.

## Правила ведения репозитория

- Один коммит = одно логическое изменение.
- Сообщения в формате [Conventional Commits](https://www.conventionalcommits.org/):
  `тип(область): описание`, например `feat(hyprland): add blur`, `fix(audio): MiniFuse default output`.
  Типы: `feat`, `fix`, `perf`, `refactor`, `chore`, `docs`.
- Стабильные состояния помечаются тегами `vX.Y`.
- Секреты (пароли, токены, ссылки подписки VPN) в репозиторий не попадают.
