# antrel-os

Личная система на базе Arch Linux. В репозитории лежит всё, чтобы получить ту же систему с нуля: установщик
(`install.sh`), настройщик (`setup.sh`), список программ и настройки. Агент держит репозиторий в актуальном
состоянии: поменяли настройку — она попадает сюда.

Сейчас это **базовая система**: Arch + KDE Plasma. Дальше её настраиваем вместе с агентом (omp), запуская его
прямо в ней.

Прошлые попытки сохранены тегами: `nixos-archive` (NixOS), `fedora-archive` (Fedora + 43PR),
`arch-hyprland-wip` (Arch + Hyprland, не доделано).

## Состав

| Слой | Что |
|---|---|
| Основа | Arch Linux, только официальные репозитории (AUR не используется) |
| Диск | раздел `antrel-os`, btrfs (подтома `@` и `@home`), сжатая подкачка в памяти (zram) |
| Загрузка | GRUB в текстовом режиме, пункт Windows в меню |
| Видео | NVIDIA, открытые модули ядра (`nvidia-open`), VA-API |
| Рабочий стол | KDE Plasma (Wayland), экран входа Plasma Login Manager |
| Звук | PipeWire |
| Программы | Firefox, Konsole, Dolphin, Kate, Ark, Spectacle, Happ (VPN), omp |
| Шрифты | Inter, JetBrains Mono Nerd Font, Noto; субпиксельное сглаживание, stem darkening |

## Как устроен репозиторий

```
install.sh          установщик: запускается с флешки Arch, ставит систему рядом с Windows
setup.sh            приводит установленную систему к репозиторию; можно запускать повторно
packages/pacman.txt программы из официальных репозиториев Arch
system/             системные файлы: копируются в / как есть (system/etc/... → /etc/...)
home/               настройки пользователя: лежат здесь, в ~ на них ссылки
links.txt           какие пути из home/ связаны ссылками с ~
track.sh            взять новую настройку под git: ./track.sh ~/.config/что-то
AGENTS.md           контекст для агента: решения, правила, чек-лист первой загрузки
docs/design/        визуальные референсы
```

Настройки из `home/` подключены ссылками: `~/.config/fontconfig` — это `~/antrel-os/home/.config/fontconfig`.
Любое изменение сразу видно в git, остаётся сделать коммит.

## Установка с нуля

### 1. Подготовка в Windows

- Свободные ~40 ГБ на диске: «Управление дисками» → правой кнопкой по `C:` → «Сжать том». Если там уже есть
  раздел от прошлой попытки (Fedora, NixOS) — правой кнопкой по нему → «Удалить том». `C:`, «Восстановление»
  и EFI не трогать. Если раздел называется `antrel-os`, его можно оставить: установщик отформатирует его заново.
- Гибернация и быстрый запуск выключены: в терминале администратора `powercfg /h off`.
- Скачать образ Arch Linux (`archlinux-x86_64.iso`) с [archlinux.org/download](https://archlinux.org/download/)
  и записать на флешку через Rufus (режим **DD**, если спросит).
- Интернет по кабелю.

### 2. Установка

1. При включении открыть меню загрузки (на Huananzhi обычно F11) и выбрать «UEFI: <флешка>», затем первый
   пункт меню. Загрузится чёрный экран с текстом и строкой `root@archiso ~ #` — это нормально.
2. Ввести (буквы — английские) и нажать Enter:

   ```sh
   curl -fsSL https://raw.githubusercontent.com/AntrelL/antrel-os/main/install.sh | bash
   ```

3. Установщик проверит компьютер, покажет диск и план и спросит `yes`. Затем пароль для пользователя
   `antrel` (два раза; при вводе ничего не отображается — так и должно быть).
4. Дальше сам: раздел, система, KDE, драйвер NVIDIA, меню загрузки с Windows. 15–40 минут.
   В конце `Done`. Если `omp did not install` — это нормально: без VPN агент не ставится, см. ниже.
5. `reboot`, вынуть флешку.

Windows и другие разделы установщик не трогает.

### 3. Первый вход

1. В меню загрузки выбрать `antrel-os`, на экране входа — пользователь `antrel` и пароль.
2. **VPN:** меню приложений → `Happ` → добавить подписку (ссылка из Happ на Windows) → подключиться.
3. **Агент:** открыть Konsole и выполнить `sudo ~/antrel-os/setup.sh` (поставит omp, если не поставился).
4. **GitHub:** `gh auth login`.
5. `cd ~/antrel-os && omp` — первая просьба: «пройди чек-лист после первой загрузки».

## Ежедневная работа

```sh
sudo pacman -Syu                 # обновить систему
sudo ~/antrel-os/setup.sh        # применить изменения из packages/ и system/ (повторный запуск безопасен)
~/antrel-os/track.sh ~/.config/X # взять под git настройки новой программы
```

## Правила ведения репозитория

- Один коммит = одно логическое изменение.
- Сообщения в формате [Conventional Commits](https://www.conventionalcommits.org/): `тип(область): описание`,
  например `feat(kde): dark theme`, `fix(audio): MiniFuse default output`.
  Типы: `feat`, `fix`, `perf`, `refactor`, `chore`, `docs`.
- Стабильные состояния помечаются тегами `vX.Y`.
- Секреты (пароли, токены, ссылки подписки VPN) в репозиторий не попадают.
